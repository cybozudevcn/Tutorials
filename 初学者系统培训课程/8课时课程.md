# kintone初级开发课程大纲

## 课程目标

通过8周课程，学员能够使用kintone的定制工具和API开发初级JavaScript应用，例如一个简单的考勤系统。

## 目标学员

具有基础IT经验的员工（例如熟悉编程概念、基础JavaScript或网页开发）。

## 课程结构

- **时长**：8周，每周一节课
- **每节课时长**：2-3小时（2小时授课，最多1小时提问/练习）
- **作业**：第2-6周布置作业，下一周提交
- **毕业项目**：第6周末布置，7-8周开发，8周后提交并评估
- **目标**：开发一个基于kintone的简单**系统

### 4. 我的第一个kintone开发：Hello World
通过一个简单的Hello World示例，熟悉kintone开发流程。  
**活动**（现场演示 + 学员模仿）：  
- **前提**
  学员每人应在环境中创建自己的space，各自的应用应该建立在该space下，以防学员之间互相干扰。
- **创建应用**  
  - 在kintone沙箱中创建一个空白应用，添加简单字段（如“标题”）。  
- **编写代码**  
  - **即时函数和严格模式**  
    - **用途**：使用立即执行函数表达式（IIFE）和严格模式（`"use strict"`）可避免全局变量污染，确保代码在kintone环境中运行稳定。  
    - **写法**：将代码包裹在IIFE中，启用严格模式以强制更规范的JavaScript编码。  
    - 示例：  
      ```javascript
      (function() {
          'use strict';
          kintone.events.on('app.record.index.show', function(event) {
              console.log('Hello World');
              return event;
          });
      })();
      ```  
  - 使用JavaScript API，在“列表页面显示后”事件（`app.record.index.show`）触发。  
- **上传代码**  
  - 在kintone应用设置中上传JavaScript文件（.js格式）。  
- **查看效果**  
  - 刷新kintone列表页面，打开浏览器开发者工具（F12），在控制台查看“Hello World”输出。  

### 5. kintone JavaScript API入门
深入了解kintone的JavaScript API，掌握基于事件的定制开发。  
- **概述**  
  - JavaScript API用于定制kintone页面（如表单、列表）的交互和逻辑。  
  - 按作用范围分为：  
    - **全局定制**：影响整个kintone环境（如导航栏修改）。  
    - **应用内定制**：仅影响特定应用（本课程重点）。  
- **重要概念：基于事件的编程**  
  - kintone页面中的用户操作（如点击、输入）会触发事件。  
  - 开发者可为特定事件注入逻辑（如显示提示、修改字段）。  
  - 常用事件列表（参考文档）：  
    - `app.record.index.show`：列表页面显示时触发。  
    - `app.record.create.show`：创建记录页面显示时触发。  
    - `app.record.edit.show`：编辑记录页面显示时触发。  
- **活动：事件逻辑实践**（现场演示 + 学员模仿）  
  - 选择三种事件（`app.record.index.show`、`app.record.create.show`、`app.record.edit.show`）。  
  - 编写代码，在每个事件触发时打印不同信息到控制台，例如：  
    ```javascript
    (function() {
        'use strict';
        kintone.events.on('app.record.index.show', function(event) {
            console.log('列表页面已加载');
            return event;
        });
        kintone.events.on('app.record.create.show', function(event) {
            console.log('创建记录页面已加载');
            return event;
        });
        kintone.events.on('app.record.edit.show', function(event) {
            console.log('编辑记录页面已加载');
            return event;
        });
    })();
    ```  
  - **课堂练习**：  
    - 学员在自己的kintone应用中实现上述代码。  
    - 打开浏览器开发者工具，查看控制台输出，确认效果。  
- **显示/隐藏字段**  
  - **功能介绍**：通过JavaScript动态显示或隐藏字段，提升用户体验。  
  - **适用场景**：记录详情、记录添加、记录编辑、记录打印页面。  
  - **前提：字段代码的意义**  
    - 字段代码（field_code）是kintone为每个字段分配的唯一标识符，用于JavaScript操作（如显示/隐藏字段）。  
    - 获取方式：在kintone应用设置的“表单”页面查看字段设置，找到对应字段的代码（如“title”或“note”）。  
    - 重要性：未正确设置字段代码或使用错误代码将导致脚本无法识别目标字段，影响功能实现。  
  - **代码示例**（现场演示 + 学员模仿）：  
    ```javascript
    (function() {
        'use strict';
        kintone.events.on('app.record.create.show', function(event) {
            kintone.app.record.setFieldShown('note', false); // 隐藏“备注”字段
            return event;
        });
    })();
    ```  
  - **课堂练习**：  
    - 在创建记录页面隐藏一个字段（如“备注”）。  
    - 验证效果：进入创建记录页面，确认字段是否隐藏。  
  - **注意**：  
    - 通过kintone应用设置查看字段代码（field_code）。  
    - 查阅文档了解支持的事件和方法（如`setFieldShown`）。

## 2. 免上传开发：让开发更快

通常我们写好JavaScript代码后需要上传到kintone测试，比较麻烦。免上传开发可以让我们在本地直接测试代码，提高效率。

- **工具**：  
  - **mkcert**：生成本地HTTPS证书，让浏览器信任本地开发环境（kintone要求HTTPS）。  
  - **Live Server**：VS Code插件，启动本地服务器，实时预览代码效果。  
- **为什么要用**：  
  - 不用每次修改都上传到kintone，节省时间。  
  - 本地调试更方便，能快速看到效果。  
- **简单步骤**：  
  1. **安装mkcert**：  
     - 下载mkcert（https://github.com/FiloSottile/mkcert）。  
     - 运行命令生成证书（Windows用`mkcert -install`，Mac/Linux类似）。  
     - 生成后得到证书文件（如`localhost.pem`）。  
  2. **安装Live Server**：  
     - 在VS Code中，打开“扩展”面板，搜索“Live Server”，安装。  
  3. **配置本地环境**：  
     - 在VS Code创建一个文件夹，放入你的`.js`文件。  
     - 用Live Server打开，浏览器会显示本地页面。  
     - 确保kintone的JavaScript代码能在本地运行（需要模拟kintone环境，老师会演示）。  
  4. **测试**：  
     - 修改代码，Live Server会自动刷新页面，查看效果。  
     - 确认无误后再上传到kintone。  
- **课堂练习**：  
  - 跟着老师安装mkcert和Live Server（如果没装好，课后问老师）。  
  - 用Live Server测试一个简单的`.js`文件，确认能运行。  
- **注意**：  
  - 初学者可能觉得配置复杂，先学会上传代码到kintone也可以，免上传开发会在后续课程深入讲解。

## 3. 获取元素和值

我们可以用JavaScript获取kintone页面上的元素（比如按钮、字段），然后操作它们。

### 3.1 获取元素
- **什么是元素**：  
  - 元素是网页上的“部件”，比如按钮、输入框、文字块，用HTML标签（如`<div>`、`<input>`）表示。  
  - **例子**：kintone的“标题”字段是一个`<input>`元素，点击“保存”是一个`<button>`元素。  
- **JavaScript原生获取元素**：  
  - **方法**：  
    - `document.getElementById('id')`：通过元素的ID获取。  
      - 例：`document.getElementById('myButton')`找到ID为`myButton`的按钮。  
    - `document.querySelector('.class')`：通过类名或CSS选择器获取。  
      - 例：`document.querySelector('.save-button')`找到类名为`save-button`的元素。  
  - **用途**：可以修改元素样式或内容，比如隐藏按钮、改变文字颜色。  
- **kintone获取元素**：  
  - kintone的原理和原生JavaScript一样，但提供了一些“快捷方式”，直接获取页面特定部分。  
  - **两类元素**：  
    1. **空白元素**：kintone页面预留的空白区域（比如菜单上方），可插入自定义内容。  
    2. **字段元素**：kintone应用的字段（比如“标题”字段的输入框）。  

- **获取空白元素**（现场演示 + 学员模仿）：  
  - **目标**：在kintone列表页面菜单上方的空白区域显示自定义文字。  
  - **代码**：  
    ```javascript
    (function() {
        'use strict';
        kintone.events.on('app.record.index.show', function(event) {
            var header = kintone.app.getHeaderMenuSpaceElement(); // 获取菜单上方空白元素
            header.innerHTML = '<h3>欢迎使用kintone！</h3>'; // 添加自定义内容
            return event;
        });
    })();
    ```  
  - **解释**：  
    - `kintone.app.getHeaderMenuSpaceElement()`：获取列表页面菜单上方的空白区域。  
    - `innerHTML`：设置空白区域的内容，比如添加一个标题。  
  - **课堂练习**：  
    1. 创建一个kintone应用（可用上周的应用）。  
    2. 写代码，在列表页面显示“欢迎使用kintone！”。  
    3. 上传代码，刷新列表页面，确认文字出现。  

- **获取空白栏元素**：  
  - **什么是空白栏**：kintone表单中的一种特殊字段（类型为“空白栏”），可以插入自定义HTML内容。  
  - **获取方式**：用`document.getElementById`或`kintone.app.record.getFieldElement`。  
  - **代码示例**：  
    ```javascript
    (function() {
        'use strict';
        kintone.events.on('app.record.create.show', function(event) {
            var space = kintone.app.record.getFieldElement('space_field'); // 空白栏字段代码
            space.innerHTML = '<p>这是一个自定义空白栏！</p>';
            return event;
        });
    })();
    ```  
  - **注意**：需要在kintone表单设置中添加“空白栏”字段，并记下字段代码（如`space_field`）。  

- **获取字段元素**（课堂练习）：  
  - **目标**：获取一个字段的元素（如“标题”），打印到控制台并改变样式。  
  - **代码**：  
    ```javascript
    (function() {
        'use strict';
        kintone.events.on('app.record.create.show', function(event) {
            var field = kintone.app.record.getFieldElement('title'); // 字段代码为title
            console.log(field); // 打印元素到控制台
            field.style.backgroundColor = 'yellow'; // 改变背景色
            return event;
        });
    })();
    ```  
  - **课堂练习**：

## 4. 字段值的获取和设置

我们可以获取或设置kintone字段的值，比如自动填写日期或显示用户输入。

- **获取字段值**：  
  - **场景**：在记录详情页面获取字段值并打印。  
  - **代码**：  
    ```javascript
    (function() {
        'use strict';
        kintone.events.on('app.record.detail.show', function(event) {
            var record = event.record; // 获取当前记录
            var titleValue = record['title']['value']; // 获取“标题”字段值
            console.log('标题值：' + titleValue); // 打印到控制台
            return event;
        });
    })();
    ```  
  - **解释**：  
    - `event.record`：包含当前记录的所有字段数据。  
    - `record['title']['value']`：获取字段代码为`title`的值。  
  - **课堂练习**：  
    1. 在kintone应用中确认“标题”字段代码。  
    2. 写代码，在记录详情页面打印“标题”值到控制台。  
    3. 测试：打开一个记录，检查控制台输出。  

- **设置字段值**：  
  - **场景**：在“添加记录”页面自动设置字段值。  
  - **代码**：  
    ```javascript
    (function() {
        'use strict';
        kintone.events.on('app.record.create.show', function(event) {
            var record = event.record;
            record['title']['value'] = '默认标题'; // 设置“标题”字段值
            return event;
        });
    })();
    ```  
  - **注意**：  
    - 设置字段值只能在`show`事件（如`app.record.create.show`）中使用，不能在`submit`事件中直接用。  
    - 需返回`event`对象以更新记录。  
  - **课堂练习**：  
    1. 写代码，在“添加记录”页面自动将“标题”字段设为“默认标题”。  
    2. 测试：打开“添加记录”页面，确认标题字段自动填充。

## 5. 事件详解：`change`、`submit`、`submit.success`

kintone的某些事件可以让我们在特定时机运行代码，下面详细讲解。

- **事件介绍**：  
  - **`change`事件**（如`app.record.create.change.<field_code>`）：  
    - **触发时机**：某个字段的值被用户修改时。  
    - **用途**：实时响应用户输入，比如输入姓名后自动更新另一个字段。  
    - **例**：当“标题”字段改变时，打印新值。  
      ```javascript
      (function() {
          'use strict';
          kintone.events.on('app.record.create.change.title', function(event) {
              var newValue = event.record['title']['value'];
              console.log('标题改为：' + newValue);
              return event;
          });
      })();
      ```  
  - **`submit`事件**（如`app.record.create.submit`）：  
    - **触发时机**：用户点击“保存”按钮时，但在记录保存到服务器前。  
    - **用途**：检查数据是否正确，比如确保字段不为空。  
    - **例**：检查“标题”字段是否为空。  
      ```javascript
      (function() {
          'use strict';
          kintone.events.on('app.record.create.submit', function(event) {
              var record = event.record;
              if (!record['title']['value']) {
                  alert('标题不能为空！');
                  event.error = '请填写标题';
              }
              return event;
          });
      })();
      ```  
  - **`submit.success`事件**（如`app.record.create.submit.success`）：  
    - **触发时机**：记录成功保存到服务器后。  
    - **用途**：显示成功提示或触发后续动作。  
    - **例**：保存成功后显示提示。  
      ```javascript
      (function() {
          'use strict';
          kintone.events.on('app.record.create.submit.success', function(event) {
              alert('记录保存成功！');
              return event;
          });
      })();
      ```  

- **课堂练习**（老师演示 + 学员模仿）：  
  - 写代码，实现以下功能：  
    1. 当“标题”字段改变时，打印新值到控制台。  
    2. 保存记录时，检查“标题”是否为空，若空则提示。  
    3. 保存成功后，弹出“记录保存成功！”提示。  
  - 测试：打开“添加记录”页面，输入标题、保存，检查控制台和提示。
