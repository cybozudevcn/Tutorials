# Kintone初级开发课程大纲

## 课程目标

通过8周课程，学员能够使用Kintone的定制工具和API开发初级JavaScript应用，例如一个简单的考勤系统。

## 目标学员

具有基础IT经验的员工（例如熟悉编程概念、基础JavaScript或网页开发）。

## 课程结构

- **时长**：8周，每周一节课
- **每节课时长**：2-3小时（2小时授课，最多1小时提问/练习）
- **作业**：第2-6周布置作业，下一周提交
- **毕业项目**：第6周末布置，7-8周开发，8周后提交并评估
- **目标**：开发一个基于Kintone的简单**系统

    - 掌握变量、函数、条件语句、循环等基础语法。

### 4. 我的第一个Kintone开发：Hello World
通过一个简单的Hello World示例，熟悉Kintone开发流程。  
**活动**（现场演示 + 学员模仿）：  
- **前提**
  学员每人应在环境中创建自己的space，各自的应用应该建立在该space下，以防学员之间互相干扰。
- **创建应用**  
  - 在Kintone沙箱中创建一个空白应用，添加简单字段（如“标题”）。  
- **编写代码**  
  - **即时函数和严格模式**  
    - **用途**：使用立即执行函数表达式（IIFE）和严格模式（`"use strict"`）可避免全局变量污染，确保代码在Kintone环境中运行稳定。  
    - **写法**：将代码包裹在IIFE中，启用严格模式以强制更规范的JavaScript编码。  
    - 示例：  
      ```javascript
      (function() {
          'use strict';
          kintone.events.on('app.record.index.show', function(event) {
              console.log('Hello World');
              return event;
          });
      })();
      ```  
  - 使用JavaScript API，在“列表页面显示后”事件（`app.record.index.show`）触发。  
- **上传代码**  
  - 在Kintone应用设置中上传JavaScript文件（.js格式）。  
- **查看效果**  
  - 刷新Kintone列表页面，打开浏览器开发者工具（F12），在控制台查看“Hello World”输出。  

### 5. JavaScript API入门
深入了解Kintone的JavaScript API，掌握基于事件的定制开发。  
- **概述**  
  - JavaScript API用于定制Kintone页面（如表单、列表）的交互和逻辑。  
  - 按作用范围分为：  
    - **全局定制**：影响整个Kintone环境（如导航栏修改）。  
    - **应用内定制**：仅影响特定应用（本课程重点）。  
- **重要概念：基于事件的编程**  
  - Kintone页面中的用户操作（如点击、输入）会触发事件。  
  - 开发者可为特定事件注入逻辑（如显示提示、修改字段）。  
  - 常用事件列表（参考文档）：  
    - `app.record.index.show`：列表页面显示时触发。  
    - `app.record.create.show`：创建记录页面显示时触发。  
    - `app.record.edit.show`：编辑记录页面显示时触发。  
- **活动：事件逻辑实践**（现场演示 + 学员模仿）  
  - 选择三种事件（`app.record.index.show`、`app.record.create.show`、`app.record.edit.show`）。  
  - 编写代码，在每个事件触发时打印不同信息到控制台，例如：  
    ```javascript
    (function() {
        'use strict';
        kintone.events.on('app.record.index.show', function(event) {
            console.log('列表页面已加载');
            return event;
        });
        kintone.events.on('app.record.create.show', function(event) {
            console.log('创建记录页面已加载');
            return event;
        });
        kintone.events.on('app.record.edit.show', function(event) {
            console.log('编辑记录页面已加载');
            return event;
        });
    })();
    ```  
  - **课堂练习**：  
    - 学员在自己的Kintone应用中实现上述代码。  
    - 打开浏览器开发者工具，查看控制台输出，确认效果。  
- **显示/隐藏字段**  
  - **功能介绍**：通过JavaScript动态显示或隐藏字段，提升用户体验。  
  - **适用场景**：记录详情、记录添加、记录编辑、记录打印页面。  
  - **前提：字段代码的意义**  
    - 字段代码（field_code）是Kintone为每个字段分配的唯一标识符，用于JavaScript操作（如显示/隐藏字段）。  
    - 获取方式：在Kintone应用设置的“表单”页面查看字段设置，找到对应字段的代码（如“title”或“note”）。  
    - 重要性：未正确设置字段代码或使用错误代码将导致脚本无法识别目标字段，影响功能实现。  
  - **代码示例**（现场演示 + 学员模仿）：  
    ```javascript
    (function() {
        'use strict';
        kintone.events.on('app.record.create.show', function(event) {
            kintone.app.record.setFieldShown('note', false); // 隐藏“备注”字段
            return event;
        });
    })();
    ```  
  - **课堂练习**：  
    - 在创建记录页面隐藏一个字段（如“备注”）。  
    - 验证效果：进入创建记录页面，确认字段是否隐藏。  
  - **注意**：  
    - 通过Kintone应用设置查看字段代码（field_code）。  
    - 查阅文档了解支持的事件和方法（如`setFieldShown`）。

## 作业
1. **补强基础知识**  
   - 自检HTML、CSS、JavaScript和网络知识的掌握情况。  
   - 建议复习：HTML DOM操作、CSS基础样式、JavaScript事件监听、JSON格式解析。  
   - 有余力的同学可通过在线资源（如MDN Web Docs）巩固上述知识。  
2. **搭建开发环境**  
   - 确保安装好Chrome/Edge浏览器和VS Code（无需Live Server扩展）。  
   - 测试：打开浏览器开发者工具，确认能查看控制台；用VS Code创建并保存一个简单.js文件。  
3. **实践显示/隐藏字段**  
   - 新建一个Kintone应用，包含两个字段：用户名（文本字段，字段代码：`username`）和密码提示问题（文本字段，字段代码：`hint`）。  
   - 实现以下功能：  
     - 在“记录添加页面”显示时（`app.record.create.show`），显示“密码提示问题”字段。  
     - 在“记录详情页面”(`app.record.detail.show`)、“记录编辑页面”(`app.record.edit.show`)、“记录打印页面”(`app.record.print.show`)，隐藏“密码提示问题”字段。  
   - **代码示例**（供参考）：  
     ```javascript
     (function() {
         'use strict';
         kintone.events.on('app.record.create.show', function(event) {
             kintone.app.record.setFieldShown('hint', true);
             return event;
         });
         kintone.events.on(['app.record.detail.show', 'app.record.edit.show', 'app.record.print.show'], function(event) {
             kintone.app.record.setFieldShown('hint', false);
             return event;
         });
     })();
     ```  
   - **提交内容**：  
     - 在学员自己的Kintone space中提交应用（包含配置和JavaScript文件）。  
     - 提交效果截图：记录添加页面（显示“密码提示问题”）和记录详情/编辑/打印页面（隐藏“密码提示问题”）。  
   - **考察点**：  
     - 正确选择事件（`app.record.create.show`、`app.record.detail.show`、`app.record.edit.show`、`app.record.print.show`）。  
     - 正确使用`kintone.app.record.setFieldShown`控制字段显示/隐藏。  
     - 使用即时函数和严格模式，确保代码规范。
