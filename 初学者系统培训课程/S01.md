## 1. 知识储备：开发kintone需要的基础技能

kintone开发需要一些前端和网络的基础知识。如果你不熟悉也没关系，下面用简单的方式解释，课后可以多复习！

### 1.1 编程语言
这些是kintone开发的“工具”，像搭积木，每种语言有不同作用。

- **HTML（网页结构）**  
  - **是什么**：HTML是网页的“骨架”，决定页面有什么内容（比如文字、输入框、按钮）。kintone的页面是用HTML构建的。  
  - **需要学什么**：  
    - 认识常见标签：`<div>`（容器）、`<input>`（输入框）、`<button>`（按钮）。  
    - 理解DOM（文档对象模型）：DOM像页面的“地图”，JavaScript可以通过它找到并修改页面内容。  
    - **例子**：`<div>Hello</div>`在页面显示“Hello”文字。  
  - **为什么重要**：kintone定制会用JavaScript修改页面元素，HTML是基础。  
  - **练习**：在浏览器开发者工具（F12）中输入`<div>测试</div>`，查看效果。

- **CSS（网页样式）**  
  - **是什么**：CSS控制网页的外观，比如颜色、大小、是否显示。  
  - **需要学什么**：  
    - 选择器：用类（`.class`）、ID（`#id`）或标签（`div`）找到要改的元素。  
    - 样式属性：如`display: none`（隐藏元素）、`color: red`（文字变红）。  
    - **例子**：`.button { color: blue; }`让按钮文字变蓝。  
  - **为什么重要**：kintone定制可以用CSS美化字段或按钮，比如改变背景色。  
  - **练习**：在开发者工具的“样式”面板，试着改一个按钮的颜色。

- **JavaScript（网页交互）**  
  - **是什么**：JavaScript让页面“动起来”，比如点击按钮后弹出提示。  
  - **需要学什么**：  
    - 基础语法：变量（`let name = "Tom";`）、函数（`function sayHello() {}`）、条件语句（`if (x > 0)`）、循环（`for`）。  
    - 事件监听：监听用户操作，如`onclick`（点击触发）、`onchange`（输入框变化触发）。  
    - DOM操作：用JavaScript改页面，比如`document.getElementById("myDiv").style.display = "none";`隐藏元素。  
    - 异步编程：简单理解为“等待数据”，后面会用到。  
    - **例子**：`document.getElementById('btn').onclick = function() { alert('点击了！'); };`  
  - **为什么重要**：kintone定制主要靠JavaScript，比如控制字段或显示提示。  
  - **练习**：在开发者工具的“控制台”输入`console.log('测试')`，看输出。

- **网络知识**  
  - **HTTP请求**：  
    - **是什么**：浏览器和服务器“对话”的方式，比如GET（获取数据）、POST（发送数据）。  
    - **例子**：kintone中，GET请求获取记录列表，POST请求添加新记录。  
  - **JSON格式**：  
    - **是什么**：一种数据格式，像“名字:值”对，kintone用它传递数据。  
    - **例子**：`{ "name": "Tom", "age": 25 }`表示姓名和年龄。  
    - **练习**：在控制台输入`console.log({ name: 'Tom' })`，看JSON格式。  
  - **浏览器开发者工具**：  
    - **是什么**：浏览器的调试工具（F12打开），查看代码运行结果或错误。  
    - **怎么用**：  
      - “控制台”（Console）：看JavaScript输出或错误。  
      - “网络”（Network）：检查与kintone服务器的通信。  
    - **练习**：按F12打开开发者工具，找到“控制台”，输入`console.log('测试')`。

- **其他**  
  - **调试技巧**：用`console.log`打印信息，检查代码是否正确。  
  - **模块化开发**：把代码写成小函数，方便复用，比如`function updateField() {}`。  

**自学建议**：  
- 不熟悉HTML/CSS/JavaScript？访问MDN Web Docs（https://developer.mozilla.org/zh-CN/），搜索“HTML入门”“CSS入门”“JavaScript入门”。  
- 课后试试在开发者工具中运行简单代码，熟悉操作。

## 4. 我的第一个kintone开发：Hello World

我们来做一个简单的kintone应用，输出“Hello World”，熟悉开发流程。

**步骤**（老师会演示，你跟着做）：  
1. **创建自己的Space**  
   - 登录kintone沙箱（老师提供链接）。  
   - 点击“创建Space”，命名为“[你的名字]-学习空间”（如“张伟-学习空间”）。  
   - 在space中创建应用，避免和其他学员冲突。  
   - **注意**：如果没创建space，代码可能互相干扰！  
2. **创建应用**  
   - 在你的space中创建空白应用，添加一个字段：  
     - 字段名：标题，类型：文本，字段代码：`title`。  
   - **怎么设置字段代码**：在kintone“表单”设置中，点击字段，输入代码（如`title`）。  
3. **编写代码**  
   - 打开VS Code，新建文件`hello.js`。  
   - **为什么要用即时函数和严格模式**：  
     - **即时函数（IIFE）**：把代码包起来，防止变量“泄露”，保持代码干净。  
     - **严格模式（"use strict"）**：让JavaScript更严格，减少错误（如不用未声明变量）。  
     - **写法**：  
       ```javascript
       (function() {
           'use strict';
           // 你的代码写在这里
       })();
       ```  
   - **完整代码**：在列表页面加载时打印“Hello World”。  
     ```javascript
     (function() {
         'use strict';
         kintone.events.on('app.record.index.show', function(event) {
             console.log('Hello World');
             return event;
         });
     })();
     ```  
     - **解释**：  
       - `kintone.events.on`：监听kintone事件。  
       - `app.record.index.show`：列表页面加载时触发。  
       - `console.log`：在控制台输出信息。  
       - `return event`：kintone要求返回事件对象。  
4. **上传代码**  
   - 在kintone应用设置中，找到“JavaScript和CSS定制”，上传`hello.js`。  
   - 点击“保存”并更新应用。  
5. **查看效果**  
   - 刷新kintone列表页面（你的space中的应用）。  
   - 按F12打开开发者工具，切换到“控制台”，看是否输出“Hello World”。  
   - **如果没看到**：  
     - 检查代码是否正确（复制示例代码）。  
     - 确认文件已上传并保存。  
     - 问老师！

**练习**：  
- 跟着老师完成以上步骤，确认控制台输出“Hello World”。  
- 保存`hello.js`，课后复习代码。

## 5. kintone JavaScript API入门

kintone的JavaScript API让页面更智能，比如显示提示或隐藏字段。

### 5.1 什么是JavaScript API
- **作用**：定制kintone页面的交互，比如点击时弹窗、隐藏字段。  
- **两种类型**：  
  - **全局定制**：影响整个kintone（比如改导航栏），我们不学。  
  - **应用内定制**：只影响当前应用（比如改表单），是我们重点。  

### 5.2 基于事件的编程
- **什么是事件**：用户在kintone页面上的操作（点击、输入）会触发事件。  
- **怎么用**：为事件写代码，当事件发生时，代码自动运行。  
- **常见事件**（更多在文档：https://kintone.dev/en/docs/）：  
  - `app.record.index.show`：列表页面加载时。  
  - `app.record.create.show`：打开“添加记录”页面时。  
  - `app.record.edit.show`：打开“编辑记录”页面时。  
- **例子**：想在添加记录时显示提示，就监听`app.record.create.show`。

**练习**（老师演示，你模仿）：  
- 写代码，在三个事件触发时打印不同信息：  
  ```javascript
  (function() {
      'use strict';
      kintone.events.on('app.record.index.show', function(event) {
          console.log('列表页面已加载');
          return event;
      });
      kintone.events.on('app.record.create.show', function(event) {
          console.log('创建记录页面已加载');
          return event;
      });
      kintone.events.on('app.record.edit.show', function(event) {
          console.log('编辑记录页面已加载');
          return event;
      });
  })();
  ```  
- **步骤**：  
  1. 在VS Code新建`events.js`，复制代码。  
  2. 上传到kintone应用（你的space）。  
  3. 打开列表、添加、编辑页面，检查控制台输出。  
  - **如果没输出**：检查事件名拼写、代码上传，或问老师。

### 5.3 显示/隐藏字段
- **作用**：用JavaScript控制字段是否显示，比如隐藏不重要的字段。  
- **适用页面**：记录详情、添加、编辑、打印页面。  
- **字段代码（field_code）**：  
  - **是什么**：kintone给每个字段的唯一“名字”，JavaScript用它找到字段。  
  - **怎么找**：  
    1. 进入kintone应用设置，点击“表单”。  
    2. 查看字段列表，找到字段的代码（比如“标题”是`title`）。  
  - **为什么重要**：代码写错字段代码，功能会失败。  
- **代码示例**（老师演示，你模仿）：  
  ```javascript
  (function() {
      'use strict';
      kintone.events.on('app.record.create.show', function(event) {
          kintone.app.record.setFieldShown('note', false); // 隐藏“备注”字段
          return event;
      });
  })();
  ```  
  - **解释**：  
    - `kintone.app.record.setFieldShown('note', false)`：在“添加记录”页面隐藏`note`字段。  
    - 改成`true`则显示字段。  
- **练习**：  
  - 在你的kintone应用（space内）添加“备注”字段（字段代码：`note`）。  
  - 写代码，在“添加记录”页面隐藏“备注”字段。  
  - 上传代码，进入“添加记录”页面，确认“备注”消失。  
  - **如果失败**：  
    - 检查字段代码（在表单设置中查看）。  
    - 确认代码上传并保存。
