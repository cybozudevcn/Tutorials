### 2. 免上传开发：让开发更快
**教学提示**：演示mkcert和Live Server配置，强调其可选性，避免初学者压力，留时间解决安装问题。  
- **工具**：  
  - **mkcert**：生成本地HTTPS证书，满足kintone的HTTPS要求。  
  - **Live Server**：VS Code插件，提供本地服务器，实时预览代码效果。  
- **为什么要用**：  
  - 免去每次修改代码后上传kintone的步骤，节省时间。  
  - 本地调试更直观，适合快速测试。  
- **步骤**：  
  1. **安装mkcert**：  
     - 下载mkcert（https://github.com/FiloSottile/mkcert）。  
     - 运行`mkcert -install`生成证书（Windows/Mac/Linux略有不同，教师需准备对应命令）。  
     - 生成证书文件（如`localhost.pem`）。  
  2. **安装Live Server**：  
     - 在VS Code“扩展”面板搜索“Live Server”，安装并启用。  
  3. **配置本地环境**：  
     - 在VS Code创建文件夹，放入`.js`文件。  
     - 用Live Server启动，浏览器显示本地页面。  
     - 模拟kintone环境（教师演示，需加载kintone JavaScript SDK）。  
  4. **测试**：  
     - 修改代码，Live Server自动刷新，查看效果。  
     - 确认无误后上传到kintone。  
- **课堂活动**（15分钟）：  
  - 演示mkcert安装和Live Server启动，运行简单`.js`文件（10分钟）。  
  - 学员尝试启动Live Server，测试`console.log('测试')`（5分钟）。  
  - **教学提示**：为初学者提供kintone上传方式作为备选，记录安装问题至提问环节。  
- **注意**：  
  - 初学者可继续使用kintone上传方式，免上传开发在后续课程深入讲解。  
  - 确保Node.js已安装（参考第1周），用于支持本地服务器。

### 3. 获取元素和值
**教学提示**：通过演示和练习，逐步讲解元素获取，强调kintone API与原生JavaScript的联系，强化字段代码准确性。  

#### 3.1 获取元素
- **什么是元素**：  
  - 网页上的“部件”，如按钮（`<button>`）、输入框（`<input>`）、文字块（`<div>`）。  
  - **例子**：kintone的“标题”字段是`<input>`元素，“保存”按钮是`<button>`元素。  
- **JavaScript原生获取元素**：  
  - **方法**：  
    - `document.getElementById('id')`：通过ID获取元素。  
      - 例：`document.getElementById('myButton')`。  
    - `document.querySelector('.class')`：通过类名或CSS选择器获取。  
      - 例：`document.querySelector('.save-button')`。  
  - **用途**：修改样式或内容，如隐藏按钮、改变文字颜色。  
- **kintone获取元素**：  
  - 原理与原生JavaScript相同，但提供便捷API获取特定元素。  
  - **两类元素**：  
    1. **空白元素**：kintone页面预留区域（如菜单上方），用于插入自定义内容。  
    2. **字段元素**：kintone应用的字段（如“标题”输入框）。  

- **获取空白元素**（现场演示 + 学员模仿）：  
  - **目标**：在列表页面菜单上方显示自定义文字。  
  - **代码**：  
    ```javascript
    (function() {
        'use strict';
        kintone.events.on('app.record.index.show', function(event) {
            var header = kintone.app.getHeaderMenuSpaceElement();
            header.innerHTML = '<h3>欢迎使用kintone！</h3>';
            return event;
        });
    })();
    ```  
    - **解释**：  
      - `kintone.app.getHeaderMenuSpaceElement()`：获取列表页面菜单上方空白区域。  
      - `innerHTML`：设置区域内容。  
  - **课堂活动**（10分钟）：  
    - 演示代码上传和效果（5分钟）。  
    - 学员在自己的space应用中实现，刷新列表页面确认文字显示（5分钟）。  
    - **教学提示**：检查学员space设置，排查未显示问题（代码错误、未上传）。  

- **获取空白栏元素**：  
  - **什么是空白栏**：kintone表单的“空白栏”字段，用于插入自定义HTML。  
  - **获取方式**：使用`kintone.app.record.getFieldElement`或`document.getElementById`。  
  - **代码示例**：  
    ```javascript
    (function() {
        'use strict';
        kintone.events.on('app.record.create.show', function(event) {
            var space = kintone.app.record.getFieldElement('space_field');
            space.innerHTML = '<p>这是一个自定义空白栏！</p>';
            return event;
        });
    })();
    ```  
  - **课堂活动**（10分钟）：  
    - 演示添加空白栏字段（字段代码：`space_field`）和代码实现（5分钟）。  
    - 学员在应用中添加空白栏字段，上传代码，确认效果（5分钟）。  
    - **教学提示**：指导学员设置字段代码，检查代码上传。  

- **获取字段元素**：  
  - **目标**：获取字段元素（如“标题”），打印到控制台，修改样式。  
  - **代码**：  
    ```javascript
    (function() {
        'use strict';
        kintone.events.on('app.record.create.show', function(event) {
            var field = kintone.app.record.getFieldElement('title');
            console.log(field);
            field.style.backgroundColor = 'yellow';
            return event;
        });
    })();
    ```  
  - **课堂活动**（15分钟）：  
    - 演示字段代码确认和代码实现，展示背景色变化（5分钟）。  
    - 学员实现代码，检查控制台输出和样式变化（10分钟）。  
    - **教学提示**：强调字段代码准确性，协助排查未生效问题（字段代码错误、事件拼写）。

#### 3.2 字段值的获取和设置
- **获取字段值**：  
  - **场景**：在记录详情页面获取字段值并打印。  
  - **代码**：  
    ```javascript
    (function() {
        'use strict';
        kintone.events.on('app.record.detail.show', function(event) {
            var record = event.record;
            var titleValue = record['title']['value'];
            console.log('标题值：' + titleValue);
            return event;
        });
    })();
    ```  
    - **解释**：  
      - `event.record`：包含当前记录的字段数据。  
      - `record['title']['value']`：获取字段代码为`title`的值。  
  - **课堂活动**（10分钟）：  
    - 演示代码实现，展示控制台输出（5分钟）。  
    - 学员实现代码，打开记录详情页面确认输出（5分钟）。  

- **设置字段值**：  
  - **场景**：在“添加记录”页面自动设置字段值。  
  - **代码**：  
    ```javascript
    (function() {
        'use strict';
        kintone.events.on('app.record.create.show', function(event) {
            var record = event.record;
            record['title']['value'] = '默认标题';
            return event;
        });
    })();
    ```  
    - **注意**：  
      - 仅在`show`事件（如`app.record.create.show`）中设置字段值。  
      - 需返回`event`以更新记录。  
  - **课堂 activity**（10分钟）：  
    - 演示代码实现，展示自动填充效果（5分钟）。  
    - 学员实现代码，确认“标题”字段自动填充（5分钟）。  
    - **教学提示**：检查字段代码和事件名称，协助排查未填充问题。

### 4. 事件详解：`change`、`submit`、`submit.success`
**教学提示**：通过演示和练习，讲解事件触发时机，突出实际应用场景（如数据验证）。  
- **事件介绍**：  
  - **`change`事件**（如`app.record.create.change.<field_code>`）：  
    - **触发时机**：字段值被用户修改时。  
    - **用途**：实时响应输入，如动态更新其他字段。  
    - **示例**：  
      ```javascript
      (function() {
          'use strict';
          kintone.events.on('app.record.create.change.title', function(event) {
              var newValue = event.record['title']['value'];
              console.log('标题改为：' + newValue);
              return event;
          });
      })();
      ```  
  - **`submit`事件**（如`app.record.create.submit`）：  
    - **触发时机**：点击“保存”按钮时，保存到服务器前。  
    - **用途**：验证数据，如检查字段是否为空。  
    - **示例**：  
      ```javascript
      (function() {
          'use strict';
          kintone.events.on('app.record.create.submit', function(event) {
              var record = event.record;
              if (!record['title']['value']) {
                  alert('标题不能为空！');
                  event.error = '请填写标题';
              }
              return event;
          });
      })();
      ```  
  - **`submit.success`事件**（如`app.record.create.submit.success`）：  
    - **触发时机**：记录成功保存后。  
    - **用途**：显示提示或触发后续动作。  
    - **示例**：  
      ```javascript
      (function() {
          'use strict';
          kintone.events.on('app.record.create.submit.success', function(event) {
              alert('记录保存成功！');
              return event;
          });
      })();
      ```  
- **课堂活动**（20分钟）：  
  - 演示三个事件实现：字段变化打印、验证标题、保存成功提示（10分钟）。  
  - 学员实现代码，测试功能（10分钟）。  
  - **教学提示**：展示事件触发时机，检查`alert`和`event.error`使用，协助排查问题。

     ```javascript
             var record = event.record;
             if (!record['task_name']['value']) {
                 alert('任务名称不能为空！');
                 event.error = '请填写任务名称';
             }
             return event;
         });
         kintone.events.on('app.record.create.submit.success', function(event) {
             alert('任务添加成功！');
             return event;
         });
     })();
     ```
