# 第1课：kintone开发前的准备与初入门

## 课程简介
本课通过基础知识、环境搭建和Hello World示例，引导学员入门kintone JavaScript API开发。

## 大纲提炼
1. **知识储备**：回顾HTML、CSS、JavaScript及网络基础（HTTP、JSON），运行`console.log('测试')`。
2. **开发文档**：介绍kintone开发者网站（https://kintone.dev），浏览新手教程和API文档。
3. **本地开发环境准备**：配置Chrome/Edge、VS Code（ESLint、Prettier），可选安装Node.js，测试`.js`文件。
4. **我的第一个kintone开发：Hello World**：创建应用，编写代码监听`app.record.index.show`，输出“Hello World”。
5. **kintone JavaScript API入门**：讲解事件驱动开发，监听事件并隐藏“备注”字段。

# 第2课：kintone JavaScript API基本功掌握

## 课程简介
本课深入JavaScript API，学习免上传开发、元素/字段值操作及`change`、`submit`、`submit.success`事件。

## 大纲提炼
1. **免上传开发**：配置mkcert和Live Server，测试本地调试。
2. **获取元素**：使用`getElementById`和kintone API获取元素，显示文字、插入HTML、修改样式。
3. **字段值的获取和设置**：通过`event.record`获取/设置字段值，自动填充“标题”。
4. **事件详解**：实现`change`打印字段变化、`submit`验证非空、`submit.success`提示。

# 第3课：kintone JavaScript API 巩固细节

## 课程简介
本课巩固JavaScript API，讲解元素获取、字段操作的细节及高级字段控制，演示真实场景任务。

## 大纲提炼
1. **获取元素时的注意事项**：获取空白部分/栏/字段元素，修改样式并绑定事件。
2. **信息的获取/设置时的注意事项**：使用`kintone.app.record.get/set`操作记录，获取查询和用户信息。
3. **显示/隐藏字段的补充**：实现组合字段动态折叠。
4. **课上演示**：完成“优先级”字段控制“备注”显示及用户姓名展示任务。

# 第4课：使用kintone REST API

## 课程简介
本课介绍kintone REST API，讲解调用方式、验证方法及JavaScript API整合，实践数据操作。

## 大纲提炼
1. **REST API 简介**：讲解RESTful原理和kintone API功能，浏览文档。
2. **kintone REST API 简单调用**：使用curl/Postman演示GET/POST请求。
3. **验证方式的介绍**：配置密码/Token验证，测试Token认证。
4. **REST API 列表的介绍**：讲解记录操作等常用API功能。
5. **使用 kintone JavaScript API 调用 REST API**：通过`kintone.api()`实现记录查询/添加。
6. **kintone User API 简介**：使用User API获取用户组织信息。
