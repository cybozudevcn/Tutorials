# 第1周：Kintone开发前的准备与初入门

**目标**：为Kintone开发做好准备，掌握基础开发流程并完成第一个Kintone定制应用（Hello World）。  
**时长**：2小时授课 + 1小时提问/练习

## 上课大纲

### 1. 知识储备（非Kintone专属，快速回顾）
为Kintone开发打基础，快速梳理必要的前置知识，学员需自检并补强。  
**教学提示**：快速讲解，重点提示学员课后自学，使用简明例子展示HTML/CSS/JavaScript应用场景。  
- **编程语言**  
  - **HTML**  
    - 掌握基本HTML结构（如`<div>`、`<input>`、`<button>`），理解Kintone页面基于HTML渲染。  
    - 熟悉DOM操作，Kintone的JavaScript定制常涉及动态修改页面元素（如更改字段样式）。  
    - **示例**：`<input id="title">`是Kintone字段的HTML结构，可用JavaScript修改其值。  
  - **CSS**  
    - 掌握基础选择器（类`.class`、ID`#id`、标签`div`）和样式属性（如`display`、`color`、`font-size`）。  
    - 理解如何通过CSS调整Kintone页面外观（如字段背景色、按钮美化）。  
    - **示例**：`.field { background: yellow; }`可改变Kintone字段背景。  
  - **JavaScript**  
    - 掌握变量（`let x = 10;`）、函数（`function doSomething() {}`）、条件语句（`if`）、循环（`for`）等基础语法。  
    - 熟悉事件监听（如`onclick`、`onchange`）和DOM操作（如`document.getElementById`）。  
    - 了解异步编程基础（如`Promise`、`async/await`），为后续REST API调用做准备。  
    - **示例**：`document.getElementById('btn').onclick = function() { alert('点击了！'); };`  
- **网络知识**  
  - **HTTP请求**：理解GET（获取数据）、POST（发送数据）请求原理，Kintone REST API依赖HTTP通信。  
  - **JSON格式**：掌握JSON结构（如`{ "name": "Tom" }`）和解析，Kintone API使用JSON传递数据。  
  - **浏览器开发者工具**：学会使用控制台（查看日志）、网络面板（检查API请求），用于调试Kintone代码。  
  - **示例**：在控制台输入`console.log({ name: 'Tom' })`查看JSON输出。  
- **其他**  
  - 基本调试技巧：通过开发者工具定位错误（如拼写错误）、查看`console.log`日志。  
  - 模块化开发：将代码封装为函数（如`function updateField() {}`），便于复用和维护。  
**课堂活动**：  
- 展示简单HTML/CSS/JavaScript代码（5分钟），让学员在浏览器开发者工具中运行`console.log('测试')`。  
- 引导学员记录不熟悉的知识点，课后自学（如MDN Web Docs：https://developer.mozilla.org/zh-CN/）。

### 4. 我的第一个Kintone开发：Hello World
通过一个简单的Hello World示例，熟悉Kintone开发流程。  
**教学提示**：分步演示，确保每位学员都能完成，强调space隔离的重要性。  
**活动**（现场演示 + 学员模仿）：  
- **前提**  
  - 每位学员在Kintone环境中创建自己的space（独立工作空间），在其中创建应用，避免互相干扰。  
  - **步骤**：登录Kintone沙箱，点击“创建Space”，命名为“[学员姓名]-学习空间”，然后在space内创建应用。  
  - **教学提示**：检查学员是否正确创建space，必要时协助设置权限（5分钟）。  
- **创建应用**  
  - 在学员自己的space中创建空白应用，添加一个文本字段（如“标题”，字段代码：`title`）。  
  - **教学提示**：演示应用创建，展示如何设置字段代码（5分钟）。  
- **编写代码**  
  - **即时函数和严格模式**  
    - **用途**：立即执行函数表达式（IIFE）避免全局变量污染，严格模式（`"use strict"`）强制规范编码，减少错误。  
    - **写法**：  
      ```javascript
      (function() {
          'use strict';
          // 代码写在这里
      })();
      ```  
    - **教学提示**：解释IIFE和严格模式的必要性，展示代码结构（5分钟）。  
  - 使用JavaScript API，在“列表页面显示后”事件（`app.record.index.show`）触发。  
  - **代码示例**：  
    ```javascript
    (function() {
        'use strict';
        kintone.events.on('app.record.index.show', function(event) {
            console.log('Hello World');
            return event;
        });
    })();
    ```  
    - **解释**：  
      - `kintone.events.on`监听事件，`app.record.index.show`表示列表页面加载。  
      - `console.log`输出到浏览器控制台。  
      - `return event`确保Kintone事件处理正常。  
- **上传代码**  
  - 在Kintone应用设置中，进入“JavaScript和CSS定制”，上传`.js`文件。  
  - **教学提示**：演示上传流程，提醒学员保存设置（5分钟）。  
- **查看效果**  
  - 刷新Kintone列表页面，按F12打开开发者工具，在“控制台”查看“Hello World”输出。  
  - **教学提示**：指导学员打开开发者工具，排查未输出问题（如文件未上传、代码错误）（10分钟）。  

### 5. Kintone JavaScript API入门
深入了解Kintone的JavaScript API，掌握基于事件的定制开发。  
**教学提示**：通过演示和练习强化事件驱动概念，突出字段代码的重要性。  
- **概述**  
  - JavaScript API用于定制Kintone页面（如表单、列表）的交互和逻辑。  
  - 按作用范围分为：  
    - **全局定制**：影响整个Kintone环境（如导航栏修改），本课程不深入。  
    - **应用内定制**：仅影响特定应用（如表单字段控制），本课程重点。  
- **重要概念：基于事件的编程**  
  - Kintone页面中的用户操作（如点击、输入）触发事件，开发者为事件添加逻辑。  
  - 常用事件（参考文档：https://kintone.dev/en/docs/）：  
    - `app.record.index.show`：列表页面显示时触发。  
    - `app.record.create.show`：创建记录页面显示时触发。  
    - `app.record.edit.show`：编辑记录页面显示时触发。  
  - **教学提示**：展示事件列表，解释触发时机（5分钟）。  
- **活动：事件逻辑实践**（现场演示 + 学员模仿）  
  - 选择三种事件（`app.record.index.show`、`app.record.create.show`、`app.record.edit.show`）。  
  - 编写代码，在每个事件触发时打印不同信息到控制台：  
    ```javascript
    (function() {
        'use strict';
        kintone.events.on('app.record.index.show', function(event) {
            console.log('列表页面已加载');
            return event;
        });
        kintone.events.on('app.record.create.show', function(event) {
            console.log('创建记录页面已加载');
            return event;
        });
        kintone.events.on('app.record.edit.show', function(event) {
            console.log('编辑记录页面已加载');
            return event;
        });
    })();
    ```  
  - **课堂练习**：  
    - 学员在自己的Kintone应用（space内）实现上述代码。  
    - 上传代码，打开列表、添加、编辑页面，检查控制台输出（10分钟）。  
    - **教学提示**：协助学员排查问题（如事件拼写错误、未返回event）。  
- **显示/隐藏字段**  
  - **功能介绍**：通过JavaScript动态显示或隐藏字段，提升用户体验。  
  - **适用场景**：记录详情、记录添加、记录编辑、记录打印页面。  
  - **前提：字段代码的意义**  
    - 字段代码（field_code）是Kintone为每个字段分配的唯一标识符，用于JavaScript操作。  
    - **获取方式**：在Kintone应用设置的“表单”页面，查看字段的“字段代码”列（如“title”或“note”）。  
    - **重要性**：错误字段代码会导致脚本失败，需仔细核对。  
  - **代码示例**（现场演示 + 学员模仿）：  
    ```javascript
    (function() {
        'use strict';
        kintone.events.on('app.record.create.show', function(event) {
            kintone.app.record.setFieldShown('note', false); // 隐藏“备注”字段
            return event;
        });
    })();
    ```  
  - **课堂练习**：  
    - 在Kintone应用中添加“备注”字段（字段代码：`note`）。  
    - 实现代码，在“创建记录”页面隐藏“备注”字段。  
    - 验证效果：进入“添加记录”页面，确认“备注”字段不可见（10分钟）。  
  - **注意**：  
    - 核查字段代码（在Kintone表单设置中查看）。  
    - 查阅JavaScript API文档（https://kintone.dev/en/docs/），了解`setFieldShown`等方法。  
  - **教学提示**：演示字段代码获取，强调文档查阅，协助学员完成练习。

3. **实践显示/隐藏字段**  
   - **任务**：  
     - 在自己的Kintone space中新建一个应用，添加字段：  
       - 用户名（文本字段，字段代码：`username`）。  
       - 密码提示（文本字段，字段代码：`hint`）。  
     - 实现功能：  
       - 在“记录添加页面”(`app.record.create.show`)显示“密码提示”字段。  
       - 在“记录详情页面”(`app.record.detail.show`)、“记录编辑页面”(`app.record.edit.show`)、“记录打印页面”(`app.record.print.show`)隐藏“密码提示”字段。  
   - **代码示例**：  
     ```javascript
     (function() {
         'use strict';
         kintone.events.on('app.record.create.show', function(event) {
             kintone.app.record.setFieldShown('hint', true);
             return event;
         });
         kintone.events.on(['app.record.detail.show', 'app.record.edit.show', 'app.record.print.show'], function(event) {
             kintone.app.record.setFieldShown('hint', false);
             return event;
         });
     })();
     ```  
   - **提交内容**：  
     - 在学员自己的Kintone space提交应用（包含配置和JavaScript文件）。  
     - 提交截图：  
       - “记录添加页面”（显示“密码提示问题”）。  
       - “记录详情/编辑/打印页面”（隐藏“密码提示问题”）。  
   - **考察点**：  
     - 正确选择事件（`app.record.create.show`、`app.record.detail.show`等）。  
     - 正确使用`kintone.app.record.setFieldShown`控制字段显示/隐藏。  
     - 使用即时函数和严格模式，确保代码规范。  
   - **教学提示**：  
     - 提供参考代码，检查学员space设置和字段代码。  
     - 提醒学员测试效果并截图，提交前确认功能正常。
