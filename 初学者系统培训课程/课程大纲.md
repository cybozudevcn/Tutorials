# 第1课：kintone开发前的准备与初入门

## 课程简介
本课为kintone开发的起点，帮助学员掌握开发前的基础知识、搭建开发环境，并通过Hello World示例熟悉kintone JavaScript API的基本使用。学员将学习查阅官方文档、配置开发工具，并完成字段显示/隐藏的实践，为后续课程奠定基础。

## 大纲提炼

1. **知识储备**  
   - **内容**：快速回顾HTML（结构与DOM操作）、CSS（选择器与样式）、JavaScript（变量、函数、事件监听、异步基础）及网络知识（HTTP请求、JSON、浏览器开发者工具）。  
   - **目标**：确保学员具备kintone开发的基础，掌握调试技巧和模块化开发理念。  
   - **活动**：在浏览器控制台运行`console.log('测试')`，记录需自学的知识点（参考MDN Web Docs）。

2. **开发文档**  
   - **内容**：介绍kintone官方开发者网站（https://kintone.dev），包括新手教程、JavaScript/REST API文档、开发范例及工具。  
   - **目标**：培养查阅文档习惯，熟悉资源获取途径。  
   - **活动**：现场浏览kintone开发者网站，探索“新手教程”和“JavaScript API”页面。

3. **本地开发环境准备**  
   - **内容**：配置Chrome/Edge浏览器、VS Code（安装ESLint、Prettier插件），可选安装Node.js以备后续复杂开发。  
   - **目标**：搭建高效开发环境，确保工具兼容kintone开发。  
   - **活动**：安装VS Code并创建`.js`文件，检查浏览器开发者工具，演示Node.js版本检查。

4. **我的第一个kintone开发：Hello World**  
   - **内容**：在kintone space中创建空白应用，编写JavaScript代码（使用IIFE和严格模式），监听`app.record.index.show`事件，输出“Hello World”。  
   - **目标**：熟悉kintone开发上传流程，完成简单定制。  
   - **活动**：学员创建应用并上传代码，检查控制台输出，排查常见问题。

5. **kintone JavaScript API入门**  
   - **内容**：讲解JavaScript API的事件驱动开发，介绍`app.record.index.show`、`app.record.create.show`等事件及字段控制方法（如`setFieldShown`）。  
   - **目标**：掌握基于事件的kintone页面定制，理解字段代码的重要性。  
   - **活动**：实现多事件监听代码（输出不同信息），隐藏“备注”字段，验证效果。


# 第2课：kintone JavaScript API基本功掌握

## 课程简介
本课巩固第1周基础，深入kintone JavaScript API，学习免上传开发以提升效率，掌握元素和字段值的获取与设置，探索`change`、`submit`、`submit.success`事件的应用。学员将通过实践实现动态字段操作和数据验证，增强kintone定制能力。

## 大纲提炼

1. **上周回顾**  
   - **内容**：复习Hello World应用、事件驱动编程（如`app.record.index.show`）、字段显示/隐藏（如`setFieldShown`），讲解作业中的事件数组技巧。  
   - **目标**：确保学员掌握第1周核心概念，解决常见问题。  
   - **活动**：演示作业实现（字段显示/隐藏），讨论字段代码、事件拼写等问题，鼓励学员分享经验。

2. **免上传开发：让开发更快**  
   - **内容**：介绍mkcert（生成HTTPS证书）和Live Server（VS Code插件，实时预览），实现本地调试，减少kintone上传步骤。  
   - **目标**：提升开发效率，熟悉本地开发流程。  
   - **活动**：演示mkcert安装和Live Server启动，运行简单`.js`文件，学员测试`console.log('测试')`。

3. **获取元素**  
   - **内容**：讲解元素获取方法（原生JavaScript如`getElementById`、kintone API如`getHeaderMenuSpaceElement`、`getFieldElement`），包括空白元素、空白栏和字段元素操作。  
   - **目标**：掌握kintone页面元素获取，动态修改内容或样式。  
   - **活动**：  
     - 在列表页面菜单上方显示“欢迎使用kintone！”。  
     - 在空白栏插入自定义HTML。  
     - 获取字段元素并修改背景色，检查控制台输出。

4. **字段值的获取和设置**  
   - **内容**：学习通过`event.record`获取字段值（如`record['title']['value']`），在`app.record.create.show`设置默认值。  
   - **目标**：实现字段值的动态获取与自动填充。  
   - **活动**：  
     - 在记录详情页面打印字段值。  
     - 在添加记录页面自动设置“标题”为默认值。

5. **事件详解：`change`、`submit`、`submit.success`**  
   - **内容**：讲解`change`（字段值变化）、`submit`（保存前验证）、`submit.success`（保存后提示）事件的触发时机和应用场景。  
   - **目标**：掌握事件驱动的数据交互与验证逻辑。  
   - **活动**：实现字段变化打印、保存时验证标题非空、保存成功提示，测试功能效果。


# 第3课：kintone JavaScript API 巩固细节

## 课程简介
本课聚焦kintone JavaScript API的细节巩固，深入探讨元素获取、字段值操作的注意事项，补充字段显示/隐藏的高级用法。学员将通过两个真实场景的演示任务，学习如何分析需求并应用API解决问题，提升定制开发的熟练度。

## 大纲提炼

1. **上周回顾**  
   - **内容**：复习免上传开发、元素获取（如`getHeaderMenuSpaceElement`）、字段值操作（如`event.record`）、`change`/`submit`/`submit.success`事件。  
   - **目标**：确保学员掌握第2周核心技能，解答常见问题。  
   - **活动**：演示上周任务（如字段值设置、数据验证），讨论代码规范和调试技巧。

2. **获取元素时的注意事项**  
   - **内容**：  
     - **空白部分**：获取页面固定区域（如菜单上方），注意适用页面（如`app.record.index.show`）和文档标注位置。  
     - **空白栏**：表单内占位元素，需预设字段代码，适用于自定义HTML插入。  
     - **字段元素**：使用`kintone.app.record.getFieldElement`，注意适用页面和不可获取字段，避免破坏DOM导致功能异常。  
     - **操作示例**：修改样式（如`field.style.backgroundColor`）、追加事件（如`field.onclick`）、插入内容（如`innerHTML`）。  
   - **目标**：掌握不同类型元素获取的注意事项和操作方法。  
   - **活动**：在列表页面添加自定义文字，在空白栏插入提示，修改字段样式并绑定点击事件。

3. **信息的获取/设置时的注意事项**  
   - **内容**：  
     - **`kintone.app.record.get()`/`set(record)`**：获取/设置整个记录对象，与`event.record`+`return event`的区别在于直接操作应用数据，适用于复杂逻辑。  
     - **`kintone.app.getQuery()`**：获取当前查询字符串，包含`order by`、`limit`等；`getQueryCondition`仅返回条件部分，适合筛选逻辑。  
     - **Lookup字段**：获取参照应用的ID（如`kintone.app.getLookupTargetAppId('lookup_field')`），需确认字段类型。  
     - **关联记录列表**：获取参照应用的ID，适用于动态联动。  
     - **用户信息**：通过`kintone.getLoginUser()`获取当前用户数据（如姓名、邮箱）。  
   - **目标**：掌握记录和查询操作的细节，理解字段类型和用户信息的使用场景。  
   - **活动**：获取记录数据并打印，解析查询条件，显示当前用户信息。

4. **显示/隐藏字段的补充**  
   - **内容**：讲解组合字段的显示/隐藏（如`kintone.app.record.setGroupFieldOpen('group_field', false)`），适用于动态折叠复杂表单。  
   - **目标**：掌握高级字段控制，提升表单交互体验。  
   - **活动**：实现组合字段在特定条件下折叠（如基于下拉选项），测试效果。

5. **课上演示**  
   - **内容**：设计两个真实场景任务，覆盖元素获取、字段操作和事件处理：  
     1. **任务1**：在“添加记录”页面，根据“优先级”下拉值动态显示/隐藏“备注”字段，并设置默认值。  
     2. **任务2**：在列表页面显示当前用户姓名，并验证记录保存时“标题”字段非空。  
   - **目标**：通过需求分析和代码实现，强化API综合应用能力。  
   - **活动**：教师演示任务分析与实现，学员模仿操作，验证效果。

# 第4课：使用kintone REST API

## 课程简介
本课介绍kintone REST API的基础知识与应用，讲解RESTful API原理、kintone中的API调用方式及验证方法，展示常用API列表，并通过kintone JavaScript API实现REST API调用。学员将通过实践掌握数据获取与操作，提升kintone应用的开发能力。

## 大纲提炼

1. **上周回顾**  
   - **内容**：复习JavaScript API细节，包括元素获取（空白部分、空白栏、字段）、字段值操作（`get`/`set`）、查询处理（`getQuery`）、字段显示/隐藏。  
   - **活动**：演示上周任务（如动态字段控制、用户信息获取），解答常见问题，检查代码规范。

2. **REST API 简介**  
   - **内容**：  
     - **RESTful API**：讲解REST架构原理（GET、POST、PUT、DELETE），HTTP请求与响应，JSON数据格式。  
     - **kintone REST API**：介绍kintone提供的API用于数据操作（如记录增删改查、应用设置），强调与JavaScript API的区别与协作。  
   - **活动**：展示kintone REST API文档（https://kintone.dev/en/docs/），浏览记录操作API示例。

3. **kintone REST API 简单调用演示**  
   - **内容**：使用常见客户端（如curl、Postman）演示kintone REST API调用，展示GET（获取记录列表）、POST（添加记录）的实际操作。  
   - **活动**：教师演示curl命令获取记录，学员使用Postman测试简单GET请求，验证JSON响应。

4. **验证方式的介绍**  
   - **内容**：  
     - **密码验证**：使用kintone用户名和密码进行API认证，适合简单测试。  
     - **Token验证**：生成API Token并用于请求，适合安全性和自动化场景。  
   - **活动**：演示密码验证和Token验证的配置与调用，学员在Postman中测试Token认证。

5. **REST API 列表的介绍**  
   - **内容**：按功能分类介绍kintone REST API，包括记录操作（获取、添加、更新、删除）、应用信息获取、字段设置、用户/权限管理等，突出常用API（如`/k/v1/record.json`）。  
   - **活动**：展示API文档，逐一讲解主要API的请求格式、参数和响应，学员记录关键API用途。

6. **使用 kintone JavaScript API 调用 REST API**  
   - **内容**：讲解在kintone JavaScript环境中通过`kintone.api()`调用REST API，结合`Promise`或`async/await`处理异步请求，实现记录查询、添加等功能。  
   - **活动**：  
     - 演示代码：使用`kintone.api()`获取记录列表并显示在列表页面。  
     - 学员实现简单记录添加功能，验证API调用结果。

7. **kintone User API 简介**  
   - **内容**：介绍kintone User API，用于管理用户信息、组织和权限，如获取用户列表、查询用户详情、更新用户角色等，适用于动态权限控制场景。  
   - **活动**：演示使用User API获取当前用户组织信息，学员测试API调用并查看JSON响应。
