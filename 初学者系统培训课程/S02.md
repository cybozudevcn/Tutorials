## 2. 免上传开发：让写代码更快

通常我们写完代码要上传到Kintone测试，很麻烦。免上传开发让你在本地电脑测试代码，改完立刻看到效果，效率更高！

- **工具**：  
  - **mkcert**：生成HTTPS证书，让浏览器信任本地环境（Kintone需要HTTPS）。  
  - **Live Server**：VS Code插件，启动本地服务器，自动刷新页面。  
- **为什么要用**：  
  - 不需要每次改代码都上传Kintone，省时间。  
  - 本地调试方便，改完代码立刻看效果。  
- **简单步骤**：  
  1. **安装mkcert**：  
     - 去https://github.com/FiloSottile/mkcert 下载mkcert。  
     - 按说明运行`mkcert -install`（Windows/Mac/Linux命令不同，老师会演示）。  
     - 完成后会生成证书文件（像`localhost.pem`）。  
  2. **安装Live Server**：  
     - 打开VS Code，点“扩展”面板，搜索“Live Server”，安装。  
  3. **配置本地环境**：  
     - 在VS Code建一个文件夹，放你的`.js`文件。  
     - 右键文件夹，选“通过Live Server打开”，浏览器会显示页面。  
     - 要跑Kintone代码，需模拟Kintone环境（老师会演示怎么弄）。  
  4. **测试**：  
     - 改代码，Live Server自动刷新页面，看效果。  
     - 确认没问题再上传到Kintone。  
- **练习**：  
  - 跟着老师装mkcert和Live Server（没装好课后问老师）。  
  - 在VS Code建个`test.js`，写`console.log('测试')`，用Live Server跑，看浏览器控制台输出。  
  - **如果失败**：  
    - 检查Live Server是否启动（右下角有提示）。  
    - 确认VS Code插件装好。  
    - 问老师！  
- **注意**：  
  - 觉得配置麻烦？没关系，先用Kintone上传代码也行，免上传开发后面会再讲。

## 3. 获取元素和值

我们可以用JavaScript“抓住”Kintone页面上的元素（像按钮、输入框），然后改它们的样子或内容。

### 3.1 获取元素
- **什么是元素**：  
  - 元素是网页上的“部件”，用HTML标签表示，比如：  
    - `<button>`：按钮（像Kintone的“保存”按钮）。  
    - `<input>`：输入框（像“标题”字段）。  
    - `<div>`：文字块或容器。  
- **JavaScript原生获取元素**：  
  - **方法**：  
    - `document.getElementById('id')`：用ID找元素。  
      - 例子：`document.getElementById('myButton')`找到ID是`myButton`的按钮。  
    - `document.querySelector('.class')`：用类名或CSS选择器找。  
      - 例子：`document.querySelector('.save-button')`找到类是`save-button`的元素。  
  - **用途**：找到元素后，可以改样式（像背景色）或内容（像文字）。  
- **Kintone获取元素**：  
  - 跟原生JavaScript原理一样，但Kintone提供“快捷方式”，直接抓页面特定部分。  
  - **两类元素**：  
    1. **空白元素**：Kintone页面预留的空白区域（像菜单上方），可以放自定义内容。  
    2. **字段元素**：Kintone应用的字段（像“标题”输入框）。  

- **获取空白元素**（老师演示，你模仿）：  
  - **目标**：在列表页面菜单上方显示“欢迎使用Kintone！”。  
  - **代码**：  
    ```javascript
    (function() {
        'use strict';
        kintone.events.on('app.record.index.show', function(event) {
            var header = kintone.app.getHeaderMenuSpaceElement();
            header.innerHTML = '<h3>欢迎使用Kintone！</h3>';
            return event;
        });
    })();
    ```  
    - **解释**：  
      - `kintone.app.getHeaderMenuSpaceElement()`：抓列表页面菜单上方的空白区域。  
      - `innerHTML`：放你想显示的内容（像标题或图片）。  
  - **练习**：  
    1. 用你的Kintone应用（可以用上周的）。  
    2. 在VS Code建`header.js`，复制代码。  
    3. 上传到Kintone应用设置（JavaScript定制）。  
    4. 刷新列表页面，看“欢迎使用Kintone！”有没有出现。  
    - **如果失败**：  
      - 检查代码有没有错（复制示例代码）。  
      - 确认文件上传并保存。  
      - 问老师！  

- **获取空白栏元素**：  
  - **什么是空白栏**：Kintone表单里的特殊字段（类型“空白栏”），可以放自定义HTML内容。  
  - **怎么获取**：用`kintone.app.record.getFieldElement`或`document.getElementById`。  
  - **代码**：  
    ```javascript
    (function() {
        'use strict';
        kintone.events.on('app.record.create.show', function(event) {
            var space = kintone.app.record.getFieldElement('space_field');
            space.innerHTML = '<p>这是一个自定义空白栏！</p>';
            return event;
        });
    })();
    ```  
    - **注意**：先在Kintone“表单”设置加个“空白栏”字段，记下字段代码（像`space_field`）。  
  - **练习**：  
    1. 在你的应用加“空白栏”字段，设字段代码为`space_field`。  
    2. 建`space.js`，复制代码，上传。  
    3. 打开“添加记录”页面，看空白栏有没有显示“这是一个自定义空白栏！”。  
    - **如果失败**：检查字段代码、代码上传，或问老师。  

- **获取字段元素**：  
  - **目标**：抓“标题”字段的元素，打印到控制台，改背景色为黄色。  
  - **代码**：  
    ```javascript
    (function() {
        'use strict';
        kintone.events.on('app.record.create.show', function(event) {
            var field = kintone.app.record.getFieldElement('title');
            console.log(field);
            field.style.backgroundColor = 'yellow';
            return event;
        });
    })();
    ```  
  - **练习**：  
    1. 在Kintone应用检查“标题”字段的代码（像`title`）。  
    2. 建`field.js`，复制代码，上传。

## 4. 字段值的获取和设置

我们可以读或改Kintone字段的值，比如自动填日期或显示用户输入的内容。

- **获取字段值**：  
  - **场景**：在记录详情页面，读“标题”字段的值，打印到控制台。  
  - **代码**：  
    ```javascript
    (function() {
        'use strict';
        kintone.events.on('app.record.detail.show', function(event) {
            var record = event.record;
            var titleValue = record['title']['value'];
            console.log('标题值：' + titleValue);
            return event;
        });
    })();
    ```  
    - **解释**：  
      - `event.record`：包含当前记录的所有字段数据。  
      - `record['title']['value']`：读字段代码为`title`的值。  
  - **练习**：  
    1. 检查应用中“标题”字段的代码（像`title`）。  
    2. 建`getValue.js`，复制代码，上传。  
    3. 打开记录详情页面，按F12看控制台，确认输出标题值。  
    - **如果失败**：  
      - 检查字段代码或事件名。  
      - 确认代码上传并保存。  

- **设置字段值**：  
  - **场景**：在“添加记录”页面，自动把“标题”设为“默认标题”。  
  - **代码**：  
    ```javascript
    (function() {
        'use strict';
        kintone.events.on('app.record.create.show', function(event) {
            var record = event.record;
            record['title']['value'] = '默认标题';
            return event;
        });
    })();
    ```  
    - **注意**：  
      - 只能在`show`事件（像`app.record.create.show`）里设置值，`submit`事件不行。  
      - 要`return event`让Kintone更新记录。  
  - **练习**：  
    1. 建`setValue.js`，复制代码，上传。  
    2. 打开“添加记录”页面，看“标题”字段有没有自动填“默认标题”。  
    - **如果失败**：  
      - 检查字段代码或事件名。  
      - 确认代码上传并保存。

## 5. 事件详解：`change`、`submit`、`submit.success`

Kintone的事件能在特定时候跑代码，比如用户改字段或点“保存”。下面讲三种事件。

- **事件介绍**：  
  - **`change`事件**（像`app.record.create.change.title`）：  
    - **什么时候触发**：用户改字段值时（像输入标题）。  
    - **用途**：实时响应，比如改标题后更新其他字段。  
    - **例子**：标题变化时打印新值。  
      ```javascript
      (function() {
          'use strict';
          kintone.events.on('app.record.create.change.title', function(event) {
              var newValue = event.record['title']['value'];
              console.log('标题改为：' + newValue);
              return event;
          });
      })();
      ```  
  - **`submit`事件**（像`app.record.create.submit`）：  
    - **什么时候触发**：点“保存”时，数据存到服务器前。  
    - **用途**：检查数据，比如标题不能空。  
    - **例子**：检查标题是否为空。  
      ```javascript
      (function() {
          'use strict';
          kintone.events.on('app.record.create.submit', function(event) {
              var record = event.record;
              if (!record['title']['value']) {
                  alert('标题不能为空！');
                  event.error = '请填写标题';
              }
              return event;
          });
      })();
      ```  
  - **`submit.success`事件**（像`app.record.create.submit.success`）：  
    - **什么时候触发**：数据成功保存后。  
    - **用途**：显示成功提示或做后续动作。  
    - **例子**：保存后弹提示。  
      ```javascript
      (function() {
          'use strict';
          kintone.events.on('app.record.create.submit.success', function(event) {
              alert('记录保存成功！');
              return event;
          });
      })();
      ```  

- **练习**（老师演示，你模仿）：  
  1. 建`events.js`，写以下功能：  
     - 标题字段变化时，打印新值到控制台。  
     - 保存时，检查标题不为空，否则提示并阻止保存。  
     - 保存成功后，弹出“记录保存成功！”。  
  2. 上传代码，测试：  
     - 打开“添加记录”页面，改标题，看控制台。  
     - 试试不填标题点保存，看提示。  
     - 正常保存，看成功提示。  
  - **如果失败**：  
    - 检查字段代码（像`title`）和事件名。  
    - 确认`alert`和`event.error`写对。  
    - 问老师！
